# Hyperframes Composition Brief: tryoncam

## Objective
A 23.5s fast, kinetic launch spot for tryoncam driven by the user's voiceover script, ending on an outro card.

## Output
- Composition: `brag-output/composition/` · Render: `brag-output/brag.mp4` · 1920x1080 · 23.5s · no music

## Source material
- `site/index.html`, `site/assets/styles.css`, `extension/content.css` (Try On pill, dark trial-room panel), `site/assets/img/*` (f-* product flats, m-* model shots), `site/assets/logo-mark.svg`
- Voiceover (verbatim, user-supplied): What if you could try anything before you buy it? / Because seeing it online isn't the same as seeing it on you. / Meet tryoncam. / Try on clothes from the stores you already shop. / Right through your camera. / Instantly. / Don't like it? Swap it. / No changing rooms. / No screenshots. / No guessing. / See it. Try it. Then decide. / tryoncam. / Three free try-ons. / Start shopping differently.

## Creative direction
Tone: default pushed to fast kinetic. Hard cuts with punch-in scale, slam-in type synced to each spoken line, holds long enough to read. Show the real product: store grid with black Try On pills, cursor click, dark tryoncam panel with live view and countdown, a garment swap.

## Visual identity
Cream #f6f5f1, ink #0e0f12, accent #3d5bf5 / #8b7cf6, live green #22c55e. Bricolage Grotesque (display), Geist (body), Geist Mono (labels).

## Audio
Voice: Kokoro af_heart at 1.1x, one clip per line (assets/vo/l01–l14.wav, silence-trimmed) — scene timing follows the voice. No music (user request). SFX: sparse, low-HF-risk Kenney picks (impactSoft on slams, click on cursor clicks, card-slide on panel open/swap, bell on the outro logo), all ≤0.6 volume so they sit under the voice.
